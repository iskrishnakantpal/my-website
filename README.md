# Marvel Comics Historical Tree

Interactive knowledge-graph style website that dynamically loads all series and explicit relationships from Google Sheets.

## Data sources
- Series: https://docs.google.com/spreadsheets/d/1B5crPF8woDq_S0Tq47ynx3Rfw8aAa6TJFHNqIer0sY/edit
- Connections: https://docs.google.com/spreadsheets/d/1Zb0OsuV9yLpv_3Z1GyFGBF2Sa04B-UcmpwxxCwOMO60/edit

## Run locally
Open `index.html` in a modern browser.

## Notes
- No backend/database is used.
- If connection sheet fails, series tree still renders with warning.
